# Project Overview
This project is based on a fictitious bank called Northfield Trust. The objective of the project is to investigate the numerous accounts associated with this bank, and draw conclusions about the transactions.

# Questions to Answer
1. Which spending categories and branches generate the most fee revenue?
2. Investigate the transaction failure rate -- does it vary by payment method and/or branch? Does it trend up or down over time?
3. Identify patterns/correlations between credit score and account status.
4. Which branches are "busiest" based on transaction volume? Does that correspond to where the most accounts are opened?
5. Are there seasonal patterns in transaction volume? Does it vary based on spending category?
